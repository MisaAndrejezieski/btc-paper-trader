# Changelog

## [0.1.0] - 2026-10-16

Initial documented release.

- Added a CustomTkinter desktop interface for BTC/BRL paper trading.
- Added online quote retrieval with CoinGecko, Binance, and a local cache fallback.
- Implemented manual and automatic simulated trades, deposits, and withdrawals.
- Added atomic persistence, transaction journaling, and startup recovery.
- Added equity/NAV and buy-and-hold benchmark histories with cash-flow adjustments.
- Added historical backtesting, CSV export, FIFO trade analytics, and risk metrics.
- Added market-news insights and a bounded 24-hour price projection.
- Documented the architecture and split the application into entry point, GUI,
  motor, and formatting modules.
